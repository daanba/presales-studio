# Changelog

## v1.2.0 — 2026-10-21
- Added **53 curated product/model records** for Cisco/Fortinet with official URLs, benchmark names, date and per-model confidence status. Missing metrics are explicitly null.
- Added model selector per BOM row, portfolio-to-BOM button, site-specific peak override and real-time per-item sizing explanation.
- Sizing checkboxes select relevant benchmark families and HA logic; no fabricated combined TLS+IPS score and no sum of HA pair throughput.
- Added independent product comparison statuses: **CONDITIONAL**, **INSUFFICIENT DATA**, **FAIL**, **SEPARATE SIZING**, **NON-CAPACITY ITEM**.
- Added `TCO?` checkbox to separate technical alternative comparison from commercial totals.
- Separated QA declared `Potvrđeno` from documented `Verifikovano` while preserving manual final approval.
- Expanded demo scenario and code-level unit checks; preserved local data storage key and GitHub Pages workflow.
- Documentation updated; separate presentation PDF created for interview preparation.

## v1.1 — previous
- Improved live discovery/QA counters and evidence-dependent verification.

## Limitations
- Not an official Comtrade/Cisco/Fortinet configurator.
- No live pricing, stock, SKU activation, guarantee of firmware compatibility or regional EOS state.
- No complete testing of simultaneous TLS + IPS throughput from vendor publications alone.
