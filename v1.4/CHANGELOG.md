## v1.4 — 21 October 2026
- Added vendor catalogue buttons for official Cisco/Fortinet product directories.
- Added manual normalized JSON import and optional direct pull from CORS-enabled HTTPS JSON sources.
- Added per-model controlled merge preview, conflict field overview, conservative default skip, append/fill blanks/full replace options.
- Added guided Technology Refresh candidate workflow and double-check checklist. No automatic 1:1 approvals.
- Added client/company records, RFQ/quote/order opportunity statuses, hardware requests, activity history, actor label, editable questionnaire templates, responses with question snapshot.
- Added CRM JSON backup/restore and fictional example data.
- Isolated v1.4 catalogue drafts, projects, CRM storage from earlier versions.
- Preserved all earlier versions as separate unchanged deploy paths.
- Known limitations: official vendor product catalogues not machine-readable in this app without normalized source/CORS; no production CRM security; no multi-user verified audit trail; no automatic technical BOM-to-RFQ linking.
